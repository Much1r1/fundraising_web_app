# FUNDRISE

**FundRise** is a modern crowdfunding platform built for Kenya, allowing users to raise funds transparently through **M-Pesa**, **PayPal**, and **card payments**.


## FEATURES

- Create and manage campaigns  
- M-Pesa (Daraja API) & PayPal payments  
- Upload campaign images/videos  
- Track progress and donations  
- Supabase authentication  
- User profiles & dashboards  
- Fully responsive design
- Admin dashobard  

---

## Tech Stack

**Frontend:** React + TailwindCSS + Vite  
**Backend:** Supabase (DB + Auth + Storage)  
**Payments:** M-Pesa Daraja API, Strpe for Paypal and Card payments  
**Hosting:** Vercel
**Version Control:** Git & GitHub
